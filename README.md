# My Dashboard

A personal project management and task tracking application with a Kanban board interface, dark mode, and cloud storage via Firebase.

## Features

- 📋 **Kanban Board** - Organize tasks in To Do, In Progress, and Done columns
- 🏷️ **Categories** - Separate Work and Personal tasks
- 📅 **Due Dates** - Track when tasks are due
- ⚡ **Priority Levels** - High, Medium, Low priority tasks
- ⏱️ **Time Estimates** - Plan how long tasks will take
- 📝 **Descriptions** - Add notes and details to tasks
- 🔗 **Attachments** - Attach files and links to tasks
- 🔄 **Recurring Tasks** - Set tasks to repeat daily, weekly, or monthly
- 🔔 **Notifications** - Get reminders for upcoming tasks
- 🔍 **Search & Filter** - Quickly find your tasks
- 🌙 **Dark Mode** - Easy on the eyes
- ☁️ **Cloud Storage** - Access from any device via Firebase

## Getting Started

1. Clone this repository
2. Install dependencies: `npm install`
3. Create a Firebase project and add your config
4. Run the development server: `npm run dev`
5. Open your browser to `http://localhost:3000`

## Tech Stack

- **Frontend**: React + Vite
- **Styling**: Tailwind CSS
- **Backend**: Firebase (Authentication & Firestore Database)
- **State Management**: React Context API
